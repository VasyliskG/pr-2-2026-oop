# FAQ — Часті запитання

---

## Встановлення та запуск

**Q: Застосунок не запускається, помилка `Cannot connect to database`**

Перевірте:
1. PostgreSQL запущено: `pg_isready` або `sudo systemctl status postgresql`
2. Логін/пароль у `application.yml` відповідають налаштуванням БД
3. БД `student_collab` існує: `psql -U postgres -c "\l"`

---

**Q: Помилка `JavaFX runtime components are missing`**

Запускайте через Maven, а не напряму:
```bash
mvn javafx:run   # правильно
java -jar ...    # неправильно (потребує модульного шляху JavaFX)
```

---

**Q: Помилка `Unsupported class file major version 65`**

Встановлена Java нижче 21. Перевірте:
```bash
java -version
```
Потрібна версія 21+.

## Акаунт та вхід

**Q: Забув пароль — як скинути?**

Скидання пароля через UI не реалізовано. Зверніться до адміністратора БД:
```sql
UPDATE users
SET password_hash = '$2a$10$...'  -- новий BCrypt-хеш
WHERE username = 'your_username';
```
Для генерації хешу можна використати онлайн BCrypt-генератор.

---

**Q: Можна мати кілька акаунтів з одним email?**

Ні. Email унікальний — система поверне помилку при реєстрації.

## Команди та ролі

**Q: Хто може видаляти учасників команди?**

Тільки ADMIN або OWNER.

**Q: Чи можна видалити OWNER з команди?**

Якщо він єдиний OWNER — ні. Спочатку призначте іншого OWNER через зміну ролі.

**Q: Як стати OWNER команди?**

Автоматично при створенні команди. Передати роль OWNER може лише поточний OWNER через **зміну ролі** учасника.

## Задачі

**Q: Задача позначена червоним — що це означає?**

Задача прострочена: дедлайн вже минув, а статус ще не `DONE`.

**Q: Чому не можу перевести задачу з `DONE` у `TODO`?**

Перехід `DONE → TODO` заборонений state machine. Допустимо лише `DONE → IN_PROGRESS`.

**Q: Хто може видалити задачу?**

Тільки ADMIN або OWNER команди.

**Q: Виконавець не бачиться у списку «Додати виконавців»**

Можливо, він вже призначений на цю задачу — призначені учасники фільтруються зі списку.

## Файли

**Q: Де фізично зберігаються файли?**

Метадані (назва, розмір, тип) зберігаються в БД. Шлях до файлу — у полі `storage_path` таблиці `files`. Фактичний файл зберігається на диску за цим шляхом.

**Q: Яке максимальне обмеження розміру файлу?**

Обмеження на рівні застосунку не встановлено. Обмежує доступний простір на диску.

**Q: Що трапиться з файлами задачі, якщо задачу видалити?**

Файли залишаться прив'язаними до команди (поле `task_id` стане `NULL`). Фізично файли не видаляються.

## Продуктивність

**Q: Чат завантажується повільно**

`LoggingAspect` логує попередження при виконанні методу > 500 мс. Перевірте логи на наявність `[SLOW]`. Можливі причини: повільне з'єднання з БД або великий обсяг повідомлень.

**Q: Скільки команд можна мати?**

Технічного обмеження немає — залежить від ресурсів БД.
